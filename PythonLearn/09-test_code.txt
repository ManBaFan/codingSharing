1. 测试代码
2. 使用pip更新第三方包：python -m pip install --upgrade package_name
-m 是使用哪个模块，install --upgrade 指更新，后面是包名
3. 只为当前用户安装指定包，python -m pip install --user pytest
    python -m pip install --user package_name
    若遇到异常，可尝试在不指定标志 --user 的情况下再次执行它
4. 单元测试：用于核实函数的某个方面有没有问题
    测试用例：一组单元测试，一起核实函数在各种情况下的行为都符合要求。
    全覆盖测试：对大型项目全覆盖测试很难，刚开始对重要组件进行测试即可；广泛使用后，再进行全覆盖测试。
5. 测试函数：当修改了代码，测试未通过时，应该检查修改的代码，而不是修改测试用例；在修改完新代码，通过测试时，进行追加测试用例。
6. 测试文件的名称以 test_ 开头，测试函数的名称以test_ 开头。
    pytest会在目录下找此开头文件，执行里面的test_ 开头的函数。
---
7. 测试类：对类进行测试
8. 在测试模块中将重复使用的实例摘取出来，使用装饰器decorator @pytest.fixture 进行标注，
那么在测试函数中，把此实例对象当作参数使用。中文叫夹具。
9. 夹具使用：夹具函数名 与 测试方法的参数名称 相同
