1. class由class关键字定义，名字首字母一定是大写，名字后面跟冒号:
2. class中默认传递参数self，必须位于第一个参数。
3. class中的主方法名称必须是,两边各有两个下划线，常用__init__
4. 如果class创建时需要传递参数，参数请写在主方法里，并且在主方法里复制给self。比如
    class Dog:
        def __init__(self,name,age):
            self.name=name
            self.age=age
5. 类实例化。
6. class的属性，定义在__init()__中
7. 属性可以有默认值，直接使用 self.arg_name=default_value 来设置。
8. 属性的值可以通过 实例对象直接调用属性名称来修改，也可以通过方法来修改。
9. 类继成，子类名（父类名），在__init()__中，声命父类init方法，super().__init__(*args)
10. 类集成，方法重写。在子类中，写一个同名的方法，就可以，父类中方法就会失效。
11. 将大类拆分成多个工作的小类，这种方法称为组合。将实例用作属性，self.arg_name = class_name()
12. 模拟实物，多迭代几次代码，但是从更高层面上解决问题。
13. 导入模块，import module_name , use case: module_name.class_name()
14. 导入类，from module_name import class_name
15. 避免使用 from module_name import *
16. 导入类或模块时，使用别名 as alias_name
17. 编码原则：先完成功能，在优化结构。也就是，可以先在一个文件里完成所有功能，然后再拆分文件。
18. Python标准库，random。random.randint(1,6)，随机生成1-6之间的整数，包含1和6.
    random.choice('a','b','l','k'),随机输出参数里的一个。
19. 在创建安全相关的程序时，不要用random模块。
20. 类名，采用驼峰式命名法，即每个单词的首字母都大写，并且不使用下划线。
21. 实例名和模块名都适用小写，并在每个单词间采用下划线。
22. 每个类和每个模块后都应该跟一个文档字符串，描述其是做什么用的。遵循函数字符串的书写风格。
23. 在类中，使用一个空行来分隔方法；在模块中，使用两个空行来分隔类。
24. 在需要同时导入标准库和你自己写的模块时，先导入标准库，再加一个空行，再导入你的库。
